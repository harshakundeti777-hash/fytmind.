# FYTMIND — Your Style. Your Rules.

A free outfit planner that runs entirely in the browser. Add the clothes you own, get outfit
suggestions for the occasion, weather and mood, plan your week and share style cards.

Made by **FANTUM** · teamfantum.cares@gmail.com

## Features
- Digital wardrobe with photos, colour scan, types, search, filters, backup and restore
- Outfit generator and a stylist chat (rule-based, built from your own wardrobe)
- Weekly planner and downloadable or shareable PNG style cards
- Style ideas for menswear, womenswear and sarees, open to everyone
- Guest mode (nothing saved) or a free local account (saved in your browser)
- Light and dark themes, mobile-first layout

## Run it
Open `index.html` in a modern browser. No build step, no server, no API keys.

## Host it free with GitHub Pages
Repository **Settings → Pages → Build and deployment → Deploy from a branch → `main` / root**.
Your site appears at `https://<your-username>.github.io/<repo-name>/`.

## Privacy and security
- Data is stored in each visitor's own browser (localStorage). There is no server or database.
- The account is a password lock on that device only. It cannot sync or recover passwords.
- Never commit API keys or secrets. This project needs none.
